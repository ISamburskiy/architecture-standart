**Альтернативы**

1. Настроить для внешнего кол-центра удаленные рабочие места в АБС для доступа к информации о ставках. Не выбрано, т.к. потребует разработки специальной роли с усеченным доступом, настройки удаленных рабочих мест для неопределенного количества пользователей.
2. Настроить для внешнего кол-центра RDP-доступ к папке в контуре АБС, выкладывать туда данные по ставкам. Не выбрано из-за более сложной настройки со стороны внешнего кол-центра для неопределенного количества пользователей + повышенная трудоемкость при обеспечении разграничения прав.
3. Настроить для внешнего кол-центра доступ через облачное хранилище по ссылке. Не выбрано, т.к. скорее всего потребует сложного согласования со службой безопасности по использованию внешней системы + вероятная потребность согласования оплаты сервиса при примерно схожем уровне удобства.
4. При интеграции с "внутренним" кол-центром также использовать пересылку по почте. Не выбрано, т.к. не предоставляет возможностей для интеграции данных по ставке в ПО кол-центра, т.е. процесс будет менее нативный.


**Недостатки, ограничения, риски**

Решение потребует доработки внешней по отношению к Банку системы Кол-центра (предположительно, силами команды АБС).

Решение потребует настройки координации с внешним кол-центром по настройке рассылки по почте с точки зрения получателей и передачи паролей к файлам.

Решение потребует настройки специального системного почтового ящика (если такого нет) и настройки доступа АБС к этому ящику.
